⚡ Kernel Space — eBPF / XDP LAYER 4 · PRE-USERSPACE
🔬 XDP Packet Filter (NIC level) 🗺 BPF Hash Map — Blocklist 🚫 IP + CIDR Drop Rules ⚡ ~50 ns drop latency 📊 25 M packets / sec per core
Runs inside the Linux kernel, attached at the NIC driver hook (XDP). Known bad IPs hit an O(1) BPF map lookup — the packet is dropped before Linux even allocates an sk_buff. ~10× faster than dropping in userspace. Cannot inspect HTTP (only sees IP/port), but that's enough for L4 DDoS & large botnets. The Rust data plane can push IPs here dynamically via sentinel block add.
Clean traffic passes to userspace TCP stack

Every phase can BLOCK (return 403/429) or PASS the request. Rules and WASM plugins register against specific phases. The data plane is completely stateless — config is hot-swapped via Arc<ArcSwap<SiteConfig>> pushed from the control plane over gRPC with zero downtime.

🟣 Control Plane — Go + Raft Cluster 3–5 NODES · HA · NOT ON REQUEST PATH
REST API · Gin · /api/v1/* gRPC Server · port 9500 Raft Consensus · leader election ~150 ms JWT / OIDC Auth RBAC · admin / operator / viewer HMAC Audit Log · tamper-evident chain Config Service · write PG → Raft → gRPC push SSE Log Stream · live logs to dashboard PostgreSQL 16 · RLS multi-tenancy LLM Copilot Proxy
Raft: 3 or 5 nodes — one leader handles writes, followers replicate state. Leader dies → new election in ~150 ms. No SPOF. RLS: every PostgreSQL table has tenant_id + row-level security — even a bug in app code cannot leak another tenant's data. Writes to rules/sites automatically propagate to all data planes via gRPC streaming config push.
